# InfoLine Frontend

Application web Angular pour la plateforme InfoLine - Actualités des technologies sportives.

## Stack Technique

- Angular 17+
- TypeScript
- Docker
- Kubernetes (AWS EKS)

## Structure du Projet
```
src/
├── app/           # Components, services, modules
├── assets/        # Images, styles, fonts
└── environments/  # Configuration par environnement
```
